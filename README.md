# PianoDeBanana

Projeto originalmente desenvolvido por Arthur Brandão (https://github.com/arthu0404) com base no vídeo feito pela canal Manual do mundo intitulado "Piano de bananas: faça o seu! #ManualMaker Aula 7, Vídeo 2" (link: https://www.youtube.com/watch?v=gTU9NunYVnM).  projeto foi utilizado para a diciplina de Práticas Básicas de Laboratório da Ilum Escola de Ciência no ano de 2025, ministradas pelo professor Dr. Leandro das Mercês Silva.

Agora o porjeto em foco é a disiplina de extenção ministrada pelos alunos da Ilum durante o segundo semestre. A principal alteração é o uso da placa ESP32 como microcontrolador base do projeto.
